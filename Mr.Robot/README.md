# Mr. Robot Penetration Test Report

This folder contains the full penetration test report for the Mr. Robot CTF machine on TryHackMe.

## Contents

- PENETRATION TEST REPORT Mr_Robot.pdf – Full report with screenshots.
- images/ – All screenshots used in the report.

- Weak Password (WordPress Admin)
- Remote Code Execution via WordPress Theme Editor
- Weak Password (robot system account)
- SUID Binary Exploitation (nmap)
